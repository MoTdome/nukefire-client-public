# NukeFire Client test soundpacks

These `.nfsp` packages are the complete example/test packs shipped with the
public Beta.73 source snapshot.

They are useful for:

- testing semantic client sound events;
- seeing the expected portable soundpack container format;
- accessibility testing with a reduced essential cue set;
- experimenting with a more immersive cue mapping.

The packs are examples of the client-side soundpack system. Server-side
semantic events and the `CR SOUNDPACK` command examples will live under
`../server-integration/` as they are extracted from the NukeFire server source.

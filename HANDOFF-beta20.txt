Client installation
-------------------
Run the self-contained upgrade installer from a terminal:

  python3 nukefire-client-beta20-install.py /path/to/nukefire-client

The installer accepts beta.19 or beta.20, creates a timestamped backup, writes only
beta.20 changed/new files, removes the retired beta.19 fine-tuning test, validates
hashes, and runs available verification. Useful options:

  --verify-only   Validate an installed beta.20 tree without changing it.
  --skip-tests    Install and hash-check without running Node tests.
  --rollback DIR  Restore a backup directory created by the installer.

Server installation
-------------------
Review server/SERVER-INSTALL-beta20.txt, then run:

  python3 install-nukefire-server-map-beta20.py /path/to/nukefire/src

The server installer backs up and replaces asciimap.c/.h, gmcp.c/.h, and gps.c/.h,
then validates their hashes and required integration markers. Compile and link in the
complete NukeFire server tree afterward.

Client/server contract
----------------------
- Client requests Room.Info, Char.GPS, NukeFire.GPS.Catalog, and NukeFire.Map.Local.
- Server BIGMAP is authoritative for room topology, exits, terrain, visited state,
  current room, GPS route, destination, and truncation/status messages.
- Server map-memory clearing command used by the client: map memory clear
- Route movement never relies on an unverified speedwalk string.
- Each direction waits for matching Room.Info and BIGMAP-center confirmation.

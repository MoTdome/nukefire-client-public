# NukeFire Client 0.3.1-beta.21

This release locks the current beta.20 development line into a unified beta.21 baseline.

Highlights include:

- Fast combat terminal and performance foundation work.
- Centered, read-only explored-room mapper with clean ordinary room tiles.
- TinTin++ alias/action paste importer with review classifications.
- Immediate live alias/action synchronization after import.
- Safe repair of simple legacy aliases with a missing closing double quote.
- Knowledge Console, GMCP, accessibility, multi-session, and workspace improvements accumulated through beta.20.

GitHub Actions builds:

- Universal macOS DMG and ZIP.
- Windows x64 installer and portable executable.
- SHA-256 checksum files for each platform.

The initial packages are unsigned. macOS Gatekeeper and Windows SmartScreen may therefore show the normal warning for an independent unsigned beta application.
